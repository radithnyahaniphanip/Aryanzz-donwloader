HELP & SUPPORT

Pusat Bantuan

Informasi singkat agar setiap fitur digunakan dengan benar.

?
Bagaimana cara mengunduh?

Tempel URL file media publik yang bisa diakses. Tautan platform membutuhkan backend atau provider yang mendukung platform tersebut.

Bisakah mencari video hanya dari judul?

Mode Cari Judul membuka hasil YouTube. Pilih video lalu salin URL-nya ke tab Link URL. Pengunduhan langsung berdasarkan judul membutuhkan API pencarian dan backend provider.

Kenapa beberapa tombol belum aktif?

Music Finder dan ekstraksi platform membutuhkan secret API atau backend eksternal. ARYANZZ menampilkan status sesuai layanan yang benar-benar terhubung.

Apakah ARYANZZ memakai paket berbayar?

Free Edition tidak memerlukan Workers Paid atau Cloudflare Containers. Backend ekstraksi platform penuh belum tersedia pada konfigurasi gratis ini.

Apakah data saya tersimpan online?

Profil, riwayat, favorit, dan tema tertentu disimpan lokal di browser.

Unduh hanya konten yang kamu miliki atau yang memang diizinkan. Website Checker memvalidasi URL, bukan menjamin situs aman. Camera Lab bukan alat medis.

Riwayat pencarian

Mode satu lagu mencoba AudD terlebih dahulu, lalu otomatis memakai Shazam fallback jika kuota atau autentikasi AudD gagal. Mode DJ memindai beberapa segmen melalui AudD Enterprise, lalu memakai Shazam fallback jika perlu. Pemindaian fallback dibatasi maksimal 30 segmen per proses.
